# Card-Tracker (VR)

Score tracker for the card games **400** (أربعمية), **Tarneeb** (طرنيب) and **Leekha** (ليخة).

Plain HTML, CSS and JavaScript: open `index.html` in a browser, no build or server needed. Games are saved in the browser's local storage.

- **400**: classic (individual scores) or partners-combined scoring, min-total-bid check, double points for bids of 5+ (optional)
- **Tarneeb**: bidder, bid 7–13, trump suit, tricks won, kaboot option
- **Leekha**: hearts, Q♠ and 10♦ per hand, lowest score wins at 101
